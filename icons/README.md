# NoteIQ Extension Icons

This directory should contain the following icon files for the Chrome extension:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Icon Design Suggestions

The icon should represent:
- 📝 Note-taking / writing
- 👁️ OCR / vision
- 🧠 AI / intelligence

## Creating Icons

You can create these icons using:
- **Online tools**: favicon.io, canva.com
- **Design software**: Figma, Adobe Illustrator, GIMP
- **AI tools**: DALL-E, Midjourney, Stable Diffusion

## Placeholder Icons

For now, you can use simple colored squares or download free icons from:
- [Feather Icons](https://feathericons.com/)
- [Heroicons](https://heroicons.com/)
- [Material Icons](https://fonts.google.com/icons)

Just make sure to create all 4 sizes (16, 32, 48, 128 pixels) for proper Chrome extension support.
